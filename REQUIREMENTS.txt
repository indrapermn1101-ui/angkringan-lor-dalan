1. DESKRIPSI SISTEM
--------------------------------------------------------------------------------
Sistem adalah aplikasi web kasir & pemesanan untuk Angkringan Lor Dalan.
Berbasis Frontend-only (HTML/CSS/JavaScript vanilla) tanpa backend/database
server. Data disimpan di browser via LocalStorage (script.js:23).

Tujuan: Mempermudah pelanggan/kasir mencatat pesanan Nasi Kucing, Sate,
Gorengan, Kopi Joss, dll, menghitung total, mengelola status pesanan,
dan rekap pembayaran/omzet secara offline.

Alur utama: Pilih Menu (+/-) -> Keranjang auto-sync ke Daftar Pesanan
(draft isAuto) -> Isi Data Pelanggan -> Simpan Pesanan -> Daftar Pesanan
-> Pembayaran -> Cetak Struk.

Referensi file: index.html:14 (app layout), script.js:30 (DOMContentLoaded),
style.css:1 (theme angkringan).


2. STAKEHOLDER & AKTOR
--------------------------------------------------------------------------------
- Pelanggan      : Memilih menu, isi nama/meja, lihat total
- Kasir / Admin  : Kelola pesanan, ubah status, tandai lunas, rekap omzet
- Juru Masak     : Melihat Daftar Pesanan status Antri/Proses untuk dimasak
- Pemilik        : Melihat statistik omzet, total pesanan (sidebar & stat-card)

Tidak ada sistem login/role; semua aktor pakai satu halaman web yang sama.

6. DATA REQUIREMENTS & MODEL
--------------------------------------------------------------------------------
6.1 Menu (DAFTAR_MENU) - 16 record (script.js:3-19)
  Field: id (string unique, e.g., 'naskuc'), nama, harga (number), kategori
  (Nasi/Sate/Gorengan/Bakaran/Minuman/Mie), gambar (path 'images/*.jpg'),
  deskripsi (string). Total 11 Makanan + 5 Minuman.

6.2 Keranjang (keranjang) - Object in-memory (script.js:22)
  Struktur: { [id]: qty } e.g., { "naskuc":2, "kopi_joss":1 }

6.3 Pesanan (dataPesanan) - Array of Object (script.js:23)
  Field per pesanan:
    nota (string ANG-0001), nama, meja, wa, jmlOrang, items (array),
    total (number), totalFormatted (string Rp), pembayaran, status,
    tanggal (YYYY-MM-DD), jam (HH:MM), catatan, isAuto (boolean draft),
    waktuSimpan (ISO string)
  Field items[]: id, nama, harga, qty, subtotal, kategori, gambar

6.4 Statistik (derived)
  - totalData = dataPesanan.length
  - totalAntri = filter status Antri/Proses Masak
  - totalOmzet = sum total where status !== Batal

6.5 Storage
  Key: "angkringan_lor_dalan" (localStorage)
  Fallback key lama: "service_hp_data" (script.js:23)
  Backup key: "backup_service_hp" jika migrasi (script.js:26)

9. BUSINESS RULES
--------------------------------------------------------------------------------
- Harga: integer Rupiah tanpa desimal, format Rp via formatRupiah() (script.js:70)
- Nota: ANG- + 4 digit zero-pad, increment (script.js:74), tidak ada cek duplikat
  jika data dihapus manual nomor bisa reuse (limitasi).
- Draft Auto: isAuto=true hanya 1 draft aktif (findIndex) (script.js:212), selalu
  di index 0 (unshift). Finalisasi hapus isAuto (script.js:327).
- Validasi Simpan: nama & meja wajib, keranjang minimal 1 item, else alert.
- Status: Antri/Proses dianggap Belum Lunas untuk omzet, Selesai/Lunas dianggap Lunas.
- Pembayaran: Tunai/QRIS/Transfer/Bon, rekap di renderPembayaran() (script.js:511).
- Pencarian: case-insensitive di nama/meja/nota/items.nama (script.js:439).
- Hapus Draft: jika hapus baris isAuto, keranjang dikosongkan (script.js:600).
- Reset Form: kembalikan tanggal/jam now, hapus draft jika ada (script.js:649).
- Jam Live: update tiap 60 detik, format id-ID HH:MM WIB (script.js:62).
- Promo: Beli 5 Nasi Kucing Gratis 1 Gorengan 17.00-19.00 (teks statis index.html:284).

14. GLOSSARY
--------------------------------------------------------------------------------

- Nasi Kucing : Nasi porsi kecil (porsi kucing) dibungkus daun pisang/kertas

- Nota       : Nomor unik ANG-0001 untuk pesanan
- Omzet      : Total pendapatan (sum total semua pesanan)
