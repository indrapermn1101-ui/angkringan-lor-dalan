Catatan:
- File LEGACY di root (script.js, style.css, AGK.jpg, images/) tetap ada untuk
  backward compat jika ada yang akses via path lama (/style.css, /AGK.jpg, /images/...)
  Backend main.py mount keduanya: /static -> static/, /images -> images/ atau static/images
- File BARU di static/ adalah yang RAPI dan direkomendasikan untuk edit ke depan
- Keduanya sync (copy) saat rapikan, jadi edit di salah satu harus sync ke lainnya
  Rekomendasi: edit di static/* (baru), lalu copy ke root jika perlu

BACKEND STATIC MOUNT (backend/main.py:50):
--------------------------------------------------------------------------------
BASE_DIR = PRAKTEK/
STATIC_DIR = BASE_DIR/static
IMAGES_DIR (legacy) = BASE_DIR/images
IMAGES_NEW = STATIC_DIR/images

- app.mount("/static", StaticFiles(directory=STATIC_DIR))  -> /static/css/style.css 200 OK
- app.mount("/images", StaticFiles(directory=IMAGES_DIR or IMAGES_NEW)) -> /images/nasi-kucing.jpg 200 OK (legacy)
- GET / -> FileResponse index.html
- GET /docs -> Swagger

CARA EDIT KE DEPAN (REKOMENDASI):
--------------------------------------------------------------------------------
- Edit CSS  : static/css/style.css  (bukan root style.css)
- Edit JS   : static/js/script.js   (lalu copy ke root script.js jika perlu: cp static/js/script.js script.js)
- Edit HTML : index.html (sudah pakai static/*)
- Tambah foto menu: taruh di static/images/nama-baru.jpg + update static/js/script.js DAFTAR_MENU + backend/seed.py
- Logo: static/assets/AGK.jpg

VSCODE TASKS (".vscode/tasks.json"):
--------------------------------------------------------------------------------
Lihat file .vscode/tasks.json untuk 8 tasks:

1. FastAPI: Install Dependencies  (pip install -r backend/requirements.txt)
2. FastAPI: Seed DB (16 Menu)    (python -m backend.seed)
3. FastAPI: Run Server            (python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000 --reload) [DEFAULT]
4. FastAPI: Run Server (No Reload)
5. FastAPI: Open Swagger Docs     (start http://127.0.0.1:8000/docs)
6. Frontend: Open Index           (start http://127.0.0.1:8000/)
7. DB: Reset & Seed               (del backend/angkringan.db & python -m backend.seed)
8. Full: Install + Seed + Run     (sequence 1+2+3)

Cara pakai di VSCode:
  Ctrl+Shift+P -> "Tasks: Run Task" -> pilih "FastAPI: Run Server"
  atau menu Terminal -> Run Task...

KEUNTUNGAN STRUKTUR RAPI:
